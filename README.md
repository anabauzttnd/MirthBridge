MirthBridge provides a high-performance, real-time data processing engine for seamless integration as a scalable adapter gateway.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/MirthBridge.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

To configure MirthBridge, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
